What does comparing two lists do?

List comparison separates two sets of values into useful groups. Common values appear in both lists. One-sided values appear in only List A or only List B. This is useful for names, IDs, URLs, keywords, spreadsheet columns, product codes and other line-based data.

The same task may be described as compare 2 lists, comparing two lists, comparing 2 lists or a list diff. This page focuses on the basic comparison itself rather than duplicating a larger suite of tools.

How this lite tool handles values

By default, surrounding spaces and blank entries are ignored, and letter case is treated as equivalent. You can turn case-insensitive matching off when capitalization must be exact. Repeated values are consolidated for a clearer comparison result.

Because the comparison runs with JavaScript in the browser, the values you paste are not sent to a comparison server by this page.

Quick questions

Can I compare spreadsheet columns?

Yes. Copy each spreadsheet column and paste it into List A or List B, with one value per line.

Can I compare lists without matching capitalization?

Yes. Leave “Ignore letter case” enabled so values such as Apple and apple are treated as the same item.

Does the page save my list data?

No comparison backend is used by this page. The comparison is performed locally in your browser.
