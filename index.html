Quick guide

How to compare two lists

List comparison is useful when you need to check two sets of names, IDs, keywords, email addresses, inventory values or other line-based data. Instead of checking rows manually, the tool normalizes the values according to your selected options and shows four useful result sets.

1

Paste both lists

Add values to List A and List B. One value per line is easiest, but comma and semicolon separators also work.

2

Choose matching rules

Decide whether capitalization matters, whether spaces should be trimmed and whether repeated values should be treated as one item.

3

Review the differences

See shared values, items unique to either side and the combined union. Copy any result with one click.

What does comparing two lists show?

A comparison separates the data into groups that answer different questions. Common items are values found in both lists. Only in List A and Only in List B reveal one-sided differences. The union combines values from both sides without repeating normalized matches.

People sometimes search for this task as compare 2 lists, comparing two lists, comparing 2 lists or a listdiff. The goal is the same: identify overlap and differences accurately without scanning every line by hand.

FAQ

Frequently asked questions

Does this tool upload my lists?

No. The comparison runs in JavaScript in your browser. This page does not send the list values to a comparison API.

Can I compare names with different capitalization?

Yes. Keep case-sensitive matching turned off to treat values such as “Example” and “example” as a match. Turn it on when capitalization must be exact.

What happens to duplicate values?

With “Compare unique values” enabled, repeated normalized entries count once. Turn that option off if you want repeated lines preserved in the prepared lists.

Can I paste comma-separated data?

Yes. New lines, commas and semicolons are accepted as separators, making it convenient to paste simple data copied from spreadsheets or text.

What is the difference between intersection and union?

The intersection contains values shared by both lists. The union contains values from either list, combined into one result set.
